## 🤖 [trading-bot](./trading-bot) — Bot de trading autónomo (Bybit spot + Claude Code)

Bot que recoge métricas de mercado, las pasa a Claude Code por CLI para que
decida, y ejecuta en Bybit solo lo que aprueba un motor de riesgo determinista.
Incluye dashboard React en tiempo real, configuración en caliente, kill switch y
cortacircuitos de pérdidas.
